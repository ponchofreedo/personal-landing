This time around, I'm migrating the site to Astro, but keeping Vue around for Typescript practice.
* ~Phase 1 - Redesign core pages in Figma (yes, Figma)~
* ~Phase 2 - Backup old branch, nuke it, and install Astro~
* ~Phase 3 - Set Vercel preview env to track this branch~
* Phase 4 - Create simple Astro scaffold to prepare static content
* Phase 5 - Start building components and styles
* Phase 6 - Ship and happy dance :)

### Project Setup

```sh
yarn install
```
* I migrated the Astro directory into a child ```./site/``` folder, so all commands sould be run from there and not from the parent ```./```

#### Compile and Hot-Reload for Development

```sh
yarn dev
```

#### Type-Check, Compile and Minify for Production

```sh
yarn build
```

#### Lint with [ESLint](https://eslint.org/)

```sh
yarn lint
```
